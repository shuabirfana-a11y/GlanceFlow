# 三个核心创新点

## 1. 从视觉信息到现实行动的可信编译

系统输出的不只是识别文本，而是带执行条件和状态的行动草案。感知、判定、确认和执行被拆成可审计阶段，未验证信息不能直接产生现实写入。

## 2. 字段级证据绑定与不确定性阻断

标题、时间、地点和截止事项都绑定 OCR 行、坐标与置信度。图像质量不足、证据缺失、时间含糊或日期星期矛盾时，系统选择重拍、补充或阻断，而不是自动猜测。

## 3. 创建、回读、回滚和精准撤销的事务闭环

活动与截止提醒按日程包原子创建；每个事件用 event_id 回读核验。部分创建或回读不一致会触发补偿删除，撤销也只使用事务保存的 event_id，不按标题模糊搜索。

普通 OCR、浏览器界面和语音识别是交互组件，不作为核心创新点。
