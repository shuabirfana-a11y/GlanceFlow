# 当前限制

- 尚未部署到真实眼镜，所报告耗时仅来自 Windows 本地 CPU 模拟器。
- Google Calendar 只有假服务契约测试；尚未完成专用真实测试日历的端到端验证。
- 评测主要使用固定种子人工构造海报和视频，不代表真实校园大规模分布。
- 自然语言时间只覆盖有限的中文绝对时间和少量相对表达。
- 无数据库，重启进程后内存会话和内存日历不会保留。
- 不支持一张通知中的多场次自动拆分；遇到多时间会阻断。
- 图像质量和证据置信度阈值尚未在大规模真实数据上标定。
- 当前不支持自动报名、地图导航、活动推荐、人脸或二维码自动脱敏。
- 用户体验测试尚未招募参与者，因此没有可报告的真实用户结果。
