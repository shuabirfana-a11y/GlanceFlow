# 隐私与安全

- 只有明确的“帮我安排”触发才开始采集，单次最多处理约 3 秒，不持续录像。
- 当前默认不保存音频；浏览器语音识别不可用时使用可见文本输入。
- 浏览器上传的临时视频在抽帧后默认删除，未选中帧立即删除，只保留当前会话的证据帧；清除会话后删除。
- 当前未实现人脸和二维码自动脱敏，因此演示与评测只使用不含个人信息和二维码的人工素材。
- 默认使用隔离内存日历。Google 适配器拒绝 `primary` 日历，要求专用测试日历与最小事件权限；当前未进行真实调用。
- 移动或姿态未知时可以处理草案，但禁止确认、创建和撤销。
- 冲突不自动改时间，重复通知不重复创建，回读异常会触发补偿回滚。
- 凭据、token、密钥和用户素材不写入日志或版本库。
