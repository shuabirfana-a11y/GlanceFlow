# 见程 GlanceFlow 项目概览

## 用户痛点

校园高价值通知常出现在海报、公告栏和线下展板中。用户看到时正在走路或赶时间，拍照之后容易遗忘；直接依赖 OCR 自动写日历，又可能把错字、模糊时间、矛盾日期或过期通知变成真实错误行动。

## 一句话方案

见程把第一视角通知编译成“带字段证据、可拒绝、可确认、可回读、可回滚、可撤销”的日程事务。

## 使用场景与闭环

用户明确说“帮我安排”后，模拟器只采集约 3 秒，自动选择质量最好的证据帧。本地 OCR 生成字段级证据，确定性安全门决定是确认、补充、重拍还是阻断；只有通过预检和结构化确认的草案才能进入日历事务。创建后按 event_id 回读，异常时补偿回滚，用户还可精准撤销。
