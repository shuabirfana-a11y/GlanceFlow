# Three-minute operator script

## 0:00–0:20 — One sentence

GlanceFlow turns a first-person view of a time-limited campus notice into an evidence-bound, user-confirmed calendar action while refusing uncertain or contradictory inputs.

## 0:20–1:05 — Normal creation

Load GF-DEMO-01. Step through Capture, OCR, Safety, Preflight, explicit confirmation, Create, Readback, Verify. Point out that the HUD contains only what the user needs.

## 1:05–1:35 — Time and evidence

Open Evidence. Show OCR line ID, confidence, source frame, eight-character image hash, and temporal role. Explain that these are public provenance fields, not hidden reasoning.

## 1:35–2:05 — Contradiction block

Load GF-DEMO-04. Run Auto. Show `CONTRADICTION_BLOCKED`, zero events, and the compact Safety panel.

## 2:05–2:35 — Conflict confirmation

Load GF-DEMO-05. Show Action Preflight detecting the course conflict. Point out that ordinary confirmation is rejected and an explicit conflict acceptance is recorded.

## 2:35–2:50 — Fault rollback

Load GF-DEMO-08. Show Readback mismatch, rollback, verified deletion, and zero remaining events.

## 2:50–3:00 — Summary

This is a repeatable Windows simulator—not Rokid validation. The contribution is evidence, permission, verification, and recovery around real-world side effects.
