# 真实素材隐私复核清单

每张素材必须全部满足后才能进入受控评测：

- [ ] 已获得通知发布方或合法素材提供者许可。
- [ ] 已获得拍摄者许可，并记录允许的使用范围。
- [ ] 画面不包含未经许可的人脸或旁观者。
- [ ] 姓名已删除或不可逆模糊。
- [ ] 手机号及其他联系方式已删除或不可逆模糊。
- [ ] 学号、工号、证件号已删除或不可逆模糊。
- [ ] 二维码、条形码和可恢复链接已删除或不可逆模糊。
- [ ] 不含账号、密码、访问令牌或内部系统凭据。
- [ ] 文件元数据不含设备所有者或精确位置等个人信息。
- [ ] 已分配匿名 sample_id，文件名不含真实身份信息。
- [ ] 第二名复核者已确认脱敏结果。
- [ ] 未脱敏原件不会提交 Git、展示或发送给无权限人员。

任一项不满足：标记为 `REJECTED_PRIVACY_REVIEW`，不得进入数据清单。
