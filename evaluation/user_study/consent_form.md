# GlanceFlow 真人测试知情同意书

## 测试目的

评估参与者能否理解系统的识别结果、拒绝原因、Action Preflight｜行动预检、回读结果和撤销提示。

## 测试内容与风险

参与者操作 Windows 本地模拟器完成六项任务。系统使用人工构造素材和隔离内存日历，不调用真实 Google Calendar。可能的不适仅限于短时视觉疲劳或对原型操作的轻微挫败感；参与者可随时休息或退出。

## 数据与隐私

记录使用随机参与者编号，不收集姓名、学号、手机号、邮箱、真实日历或真实校园通知。记录包括任务是否完成、耗时、确认次数、重拍次数、误操作、HUD 理解以及自定义 1—5 分评价。原始记录仅用于本项目验证，不公开可识别个人的信息。
