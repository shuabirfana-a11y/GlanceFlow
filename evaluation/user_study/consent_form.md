# GlanceFlow 真人测试知情同意书

## 测试目的

评估参与者能否理解系统的识别结果、拒绝原因、Action Preflight｜行动预检、回读结果和撤销提示。

## 测试内容与风险

参与者操作 Windows 本地模拟器完成六项任务。系统使用获许可且脱敏的测试素材和隔离内存日历，不调用真实 Google Calendar。若真实校园素材尚未采集，则仅使用明确标注的合成素材。可能的不适仅限于短时视觉疲劳或对原型操作的轻微挫败感；参与者可随时休息或退出。

## 数据与隐私

分析记录使用 `P01` 格式匿名编号，不收集姓名、学号、手机号、邮箱或真实日历。记录包括任务是否完成、耗时、确认/澄清/重拍次数、误操作、HUD 理解以及自定义 1—5 分评价。签名同意书与分析数据分开保管，不提交 Git；公开报告不包含可识别个人的信息。
