# GlanceFlow 真人测试问卷

这是项目自定义问卷，不是 SUS 或 NASA-TLX。结构化日志使用以下四项 1—5 分量表：

- HUD 理解度：1 完全不理解，5 完全理解；
- 主观可信度：1 完全不信任，5 非常信任；
- 使用负担：1 非常低，5 非常高；
- 继续使用意愿：1 完全不愿意，5 非常愿意。

以下陈述用于访谈提示，不另行伪装成标准化量表：

1. 我能理解系统识别出的标题、时间、地点和截止事项。
2. 我能理解系统为什么要求补充信息、重拍或拒绝执行。
3. 我能理解 Action Preflight｜行动预检发现的重复或冲突。
4. 我信任系统只在明确确认后写入日历。
5. 创建后的回读提示让我理解写入是否成功。
6. 精准撤销功能让我更安心。
7. HUD 提示足够简洁。
8. 整体操作负担较低。
9. 在类似校园通知场景中，我愿意继续使用该系统。

开放问题：

- 哪一步最难理解？
- 哪个提示最需要改进？
- 还有哪些安全顾虑？

当前无真实答卷，不生成均值或结论。
