# GlanceFlow 真人测试问卷

请按 1—5 分作答：1 表示“非常不同意”，5 表示“非常同意”。这是项目自定义问卷，不是 SUS。

1. 我能理解系统识别出的标题、时间、地点和截止事项。
2. 我能理解系统为什么要求补充信息、重拍或拒绝执行。
3. 我能理解 Action Preflight｜行动预检发现的重复或冲突。
4. 我信任系统只在明确确认后写入日历。
5. 创建后的回读提示让我理解写入是否成功。
6. 精准撤销功能让我更安心。
7. HUD 提示足够简洁。
8. 整体操作负担较低。
9. 在类似校园通知场景中，我愿意继续使用该系统。
