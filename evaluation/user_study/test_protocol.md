# 真人用户测试协议

## 环境与准备

1. 使用 Windows 本地 CPU 模拟器、已获许可并脱敏的测试素材（真实素材尚未采集时仅使用合成素材）和全新隔离内存日历。
2. 确认未配置真实 Google Calendar 凭据，不采集真实姓名、联系方式或日程。
3. 为参与者分配 `P01` 格式匿名编号，完成知情同意后才开始记录。
4. 研究人员不得暗示正确答案，只能读出统一任务说明。

## 六项任务

1. **T1 普通活动**：识别正常活动并创建主活动。
2. **T2 活动＋截止**：识别活动和报名截止并创建关联日程包。
3. **T3 模糊画面**：理解重拍提示，系统不得猜测执行。
4. **T4 日期矛盾**：理解系统为何 BLOCKED。
5. **T5 日程冲突**：理解 Action Preflight｜行动预检并由用户决定。
6. **T6 撤销**：按 event_id 撤销刚才验证成功的安排并核验事务状态。

## 每项任务记录

- 是否完成与完成时间；
- 确认次数、澄清次数、重拍次数和误操作；
- 是否理解 HUD 提示；
- 观察记录，但不得记录可识别个人身份的信息。

## 结束流程

参与者填写自定义 1—5 分问卷。研究人员确认记录完整后清除会话证据帧。该问卷不是 SUS，不计算 SUS 分数。

当前协议尚未执行；不得预填参与者或任务结果。
