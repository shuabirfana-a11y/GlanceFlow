# 真人用户测试协议

## 环境与准备

1. 使用 Windows 本地 CPU 模拟器、人工构造素材和全新隔离内存日历。
2. 确认未配置真实 Google Calendar 凭据，不采集真实姓名、联系方式或日程。
3. 为参与者分配随机编号，完成知情同意后才开始记录。
4. 研究人员不得暗示正确答案，只能读出统一任务说明。

## 六项任务

1. 从清晰通知创建普通活动。
2. 从通知创建活动和截止提醒日程包。
3. 面对模糊画面，理解提示并完成重拍。
4. 面对日期与星期矛盾，解释系统为何拒绝。
5. 面对日程冲突，理解 Action Preflight｜行动预检并决定是否继续。
6. 按 event_id 撤销刚才验证成功的安排。

## 每项任务记录

- 是否完成与完成时间；
- 确认次数、重拍次数和误操作；
- 是否理解 HUD 提示；
- 观察记录，但不得记录可识别个人身份的信息。

## 结束流程

参与者填写自定义 1—5 分问卷。研究人员确认记录完整后清除会话证据帧。该问卷不是 SUS，不计算 SUS 分数。
