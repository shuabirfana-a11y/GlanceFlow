# Vision adapter benchmark

The benchmark must use the same existing synthetic image manifest for each
adapter. RapidOCR remains the default. On this Stage 12 environment PaddleOCR is
not installed, so PaddleOCR is reported as `NOT_EVALUATED`; no measurements are
invented. A future run records successful samples, evidence completeness, OCR
latency, bbox/confidence availability, failures, and dependency versions.
